8. Lingkungan pengujian & catatan

  • Server: next start (build produksi Next.js 16.4.2), Node.js 22, database MariaDB 10.11 (MySQL-compatible) dengan migration & seeder project.
  • Browser: Chromium (Playwright 1.64). Foto uji galeri memakai URL contoh Cloudinary (gambar tidak dimuat di lingkungan uji karena akses jaringan terbatas; logika urutan/status/hapus/lightbox tetap tervalidasi).
  • Skor Lighthouse lokal bersifat indikatif; ulangi dengan PageSpeed Insights setelah deploy di domain produksi (jaringan CDN Netlify umumnya lebih cepat).
  • Item pasca-deploy: HTTPS di domain perusahaan, upload foto ke akun Cloudinary production, uji di Safari iOS/Firefox perangkat nyata.
